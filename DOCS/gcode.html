Grabber command parameters

VORTAC_CALIBRATE

Builds and stores the LUT — run SAVE_CONFIG after. Full workflow in Calibration.

ParameterDefaultMeaning
SAMPLES180bins per revolution (LUT size)
SPEED40sweep speed (deg/s)
TURNS2revolutions per direction; last turn wins
DIRbothcw, ccw, or both (midpoint stored, backlash reported)
PHASEstep/2pre-roll so the sensor seam falls between bins
SETTLE0.10dwell (s) after each step before reading
READS8direct SPI reads per bin (circular-meaned)
READ_DWELL0.001pause (s) between the reads of one bin

VORTAC_MOVE

Closed-loop move to an absolute true angle. cw means increasing true angle.

ParameterDefaultMeaning
TARGET0.0target true angle (deg)
MODEshortestshortest, cw, or ccw
SPEEDconfig speedmove speed (deg/s)
TOL2.0acceptance tolerance (deg, shortest-distance)
BACKOFF0.5·TOLcw/ccw only: minimum stop-short distance per pass (clamped < TOL)
GUARD_FRAC0.05cw/ccw only: stop short by this fraction of the remaining distance
MAX_ITERS10maximum measure/move passes
READS2sensor reads per measurement (circular median)
READ_SETTLE0.010dwell (s) before each measurement

VORTAC_ENGAGE / VORTAC_DISENGAGE

Closed-loop move to engage_pos (or an explicit ANGLE=<deg>) / disengage_pos, using the configured engage_mode / disengage_mode as the direction constraint. Equivalent to VORTAC_MOVE TARGET=<pos> with that mode.

VORTAC_SET_ZERO

Stores the current LUT-corrected angle as zero_pos_offset — run SAVE_CONFIG after. Approach the reference position in the operating direction if you use cw/ccw modes.

VORTAC_MESURE

Diagnostic sweep over one revolution; prints rawPairs / lutPairs / finalPairs for dev_scripts/plotData.py.

ParameterDefaultMeaning
SAMPLES90measurement points over one revolution
SPEED60sweep speed (deg/s)

Manager command notes

  • TOOL= parameters of VORTAC_LOAD, VORTAC_SET_CURRENT_TOOL and VORTAC_DOCK_SAVE_POS accept the tool name (case-insensitive, e.g. miniGrey), T<n>, or a bare index — TOOL=miniGrey and TOOL=T1 both work.
  • The T<n> commands are registered from each tool's tool_index, which comes from the include order in tools.cfg — tool ids are names like miniGrey; dashboards show the display prefix <name><index> (miniGrey1_logo_rgb, …).
  • VORTAC_DETECT establishes the dock map tool changes rely on — run it before the first tool change (e.g. in PRINT_START). Docked tools come from the strobe map; a grabbed tool is assigned the first free dock with calibrated positions for it. A tool is parked back at the dock it was fetched from (resolution chain: detection map → fetch origin → optional home_dock). It accepts DEBUG=1 for verbose per-strobe output — useful when bringing up a new tool.
  • VORTAC_DOCK_CAL_SAVE refuses while the gantry is tilted or when no dock/tool was selected via VORTAC_SELECT_DOCK.
  • All probe-based commands (QUAD_GANTRY_LEVEL, BED_MESH_CALIBRATE, PROBE*) are guarded by the manager and refuse while a tool is held — run VORTAC_UNLOAD first.
