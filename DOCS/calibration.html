Calibration

Three calibrations make the toolchanger work: the grabber's angle lookup table, its zero position, and each dock's XYZ position. Everything a printer needs on top of that — QGL, bed mesh, offsets — is in Print Calibration.

Calibration checklist

1 — Build the angle lookup table

Prerequisites: [vortac_grabber] loads without errors, and the grabber can rotate freely (no tool attached).

VORTAC_CALIBRATE

By default the grabber sweeps 2 full revolutions clockwise and 2 counterclockwise, sampling 180 bins. At each bin it settles, takes 8 direct SPI reads of the AS5047D and stores their circular mean; per direction the last revolution wins, and the saved LUT is the per-bin midpoint of both directions. The cw/ccw spread is reported as a direct backlash measurement (Backlash … mean/max).

ParameterDefaultMeaning
SAMPLES180bins per revolution (LUT size)
SPEED40sweep speed (deg/s)
TURNS2revolutions per direction; last turn wins
DIRbothcw, ccw, or both (cw + ccw, midpoint stored, backlash reported)
PHASEstep/2pre-roll so the sensor seam falls between bins
SETTLE0.10dwell (s) after each step before reading
READS8direct SPI reads per bin (circular-meaned)
READ_DWELL0.001pause (s) between the reads of one bin

On success Klipper reports Calibration OK. lookup_table saved (…) — persist it with SAVE_CONFIG.

Good to know: which DIR to pick

DIR=both (the default) averages out gear backlash and tells you how big it is. If your engage/disengage moves are direction-constrained (engage_mode/disengage_mode = cw or ccw), calibrating with only that direction (DIR=cw or DIR=ccw) puts the LUT exactly on the operating flank instead of the midpoint.

Good to know: why direct SPI reads instead of the bulk stream

Klipper's bulk angle stream was lossy at sub-bit precision — direct reads are required for trustworthy LUTs. (Historical trap: bulk angle data from Klipper is in radians × 10 000, so any consumer must convert with (raw / 10000.0) · 180/π.)

2 — Set the zero position

Move the grabber to its mechanical reference position. If you use engage_mode/disengage_mode = cw or ccw, approach the reference in that same direction (so backlash is loaded the same way as in operation). Then:

VORTAC_SET_ZERO
SAVE_CONFIG

VORTAC_SET_ZERO may also be run directly after VORTAC_CALIBRATE, before saving — one SAVE_CONFIG then persists both values (lookup_table and zero_pos_offset).

3 — Verify

VORTAC_SIMPLE_READ      ; prints raw and true angle
VORTAC_MOVE TARGET=90   ; closed-loop test move

The true angle should read ~0° at the reference position, and VORTAC_MOVE should reach its target within tolerance (default ±2°) in 1–2 moves.

Full-revolution diagnostic sweep

To verify the LUT linearizes the full 360°:

VORTAC_MESURE SAMPLES=180

It steps through one full revolution and prints three data sets: rawPairs (commanded vs. raw sensor), lutPairs (LUT-corrected) and finalPairs (LUT + zero offset). Paste a set into dev_scripts/plotData.py to plot it: rawPairs may be arbitrarily non-linear, but lutPairs/finalPairs must form a straight line with slope 1 (one clean wrap at the 360° seam). The sweep starts at the current position, so the line is offset — the slope is what matters.

4 — Calibrate dock positions

Per dock, with the tool parked in it and the gantry frame-flat. The FLAT toggle (console or the panel's Flatten button) also switches into the dock coordinate system — bed mesh and gcode offset are parked, so the jogging below happens in exactly the frame the dock positions are replayed in; VORTAC_GANTRY_TILT hands both back afterwards (see two coordinate systems):

VORTAC_GANTRY_FLAT
G28                           # if not homed
VORTAC_SELECT_DOCK DOCK=dock0 # detects the tool in dock0 and selects it
# jog the toolhead to the exact hooked/engage position in the dock
VORTAC_DOCK_CAL_SAVE
SAVE_CONFIG
  • VORTAC_SELECT_DOCK runs VORTAC_DETECT, stores the detected dock/tool pair, and fails if the selected dock has no detected tool.
  • VORTAC_DOCK_CAL_SAVE refuses if the gantry is tilted (dock geometry is only valid frame-flat) or no dock/tool was selected.
  • The saved Z is the hooked/engage height. Tool loading uses that saved Z directly, then lifts by dock_z_clearance; unloading approaches at saved Z + dock_z_clearance, drops to saved Z, then disengages.

Manual fallback (saves the current position without the detection context — TOOL= accepts the tool name, case-insensitive, T<n>, or a bare index):

VORTAC_DOCK_SAVE_POS TOOL=miniGrey DOCK=dock0
SAVE_CONFIG
Persistence always goes through SAVE_CONFIG

All calibration results (lookup_table, zero_pos_offset, params_dockN_x/y/z) are staged via Klipper's configfile.set and only written to disk when you run SAVE_CONFIG — which restarts Klipper. Don't skip it, or the calibration is gone after the next restart.

Next steps

With the grabber and every dock calibrated, the toolchanger side is done. What is still missing before a print is the printer side — gantry levelling, the Z reference, per-tool offsets, the bed mesh and the per-tool extruder work: continue with Print Calibration, then First Print.
