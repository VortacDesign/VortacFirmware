Vortac Firmware

Klipper plugins and configuration files for the Vortac Toolchanger — a custom 3D-printer toolchanger with CAN-bus tool boards, an angle-sensor-driven grabber, and ARGB-based dock detection.

What is this repository?

This is not a standalone application. The Python files under klippy/extras/ are loaded into Klipper at runtime as Klipper extras, and the files under configs/ are consumed by Klipper at printer startup. Everything runs on the printer's Raspberry Pi — there is no build step, no test suite, and nothing to compile.

The primary branch is development, not main.

The machine in one paragraph

The Vortac is a CoreXY printer with a four-Z gantry and a row of tool docks. Each tool is a complete toolhead (extruder, hotend, fans, LEDs, accelerometer) driven by its own CAN-bus board. A single grabber mechanism on the carriage picks tools up and puts them back: a stepper rotates a hook, and an AS5047D magnetic angle sensor closes the loop so engage/disengage angles are hit reliably. Which tool sits in which dock is discovered electrically: each dock's ARGB LED green channel actively pulls the tool's dock sense pad low (blue mirrors green as a status LED, red powers the parked board) — strobing one dock's green channel at a time reveals the mapping, and outside of detection all docks keep it on so the sense logic stays valid.

Architecture at a glance

  • vortac_manager — the coordinator. Registers T0/T1/…, runs the tool-change sequence, owns dock detection and the probe guard.
  • vortac_grabber — hardware only: reads the AS5047D over SPI, linearizes it through a calibrated lookup table, and drives the grabber stepper in a closed loop.
  • vortac_tool — one logical [vortac_tool <name>] section per tool (injected from the PCB template by include_with): sense pins, G-code offsets, saved dock positions, activate/deactivate hooks.
  • vortac_qgl_state — toggles the four-Z gantry between frame-flat (dock geometry valid) and bed-flat (print geometry valid) without re-probing.
  • include_with — instantiates one shared toolboard PCB template N times under remapped MCU namespaces.

Quick start

# on the Pi
git clone https://github.com/VortacDesign/VortacFirmware.git ~/vortac
cd ~/vortac && sudo ./install.sh
sudo systemctl restart klipper

Then continue with Installation & Setup — configs, tools and calibration.

Good to know: why editing here updates the printer

install.sh symlinks every plugin into Klipper's klippy/extras/ and bind-mounts configs/vortac_configs/ into ~/printer_data/config/. A systemd .path unit watches the git branch ref, so every git pull re-runs the installer automatically. The only manual step after pulling is sudo systemctl restart klipper.
